# Termosh 0.1.0 — beta 2

## Что нового

- **Экран первого запуска.** Понятное приветствие и два пути: добавить
  сервер или импортировать из OpenSSH / ConnectBot.
- **Человеческие ошибки подключения.** Вместо `UserAuthException:
  Exhausted available authentication methods` — «Неверный пароль или
  SSH-ключ. Проверьте логин, пароль и настройки аутентификации».
- **Пустые состояния с подсказками** для сниппетов, ключей, туннелей,
  TOTP и логов.
- **Понятное сообщение после импорта** — что импортировано и кнопка
  «К серверам».
- **Постоянные сессии через tmux.** Новая опция в настройках сервера:
  включите, и сессия будет жить на сервере, переживая закрытие
  приложения и потерю сети.
- **Иконка уведомления** — символ терминала `>_` вместо стрелки
  скачивания.

## Pro-функции

Часть функций теперь помечена замком в бесплатной версии:
SFTP, port-forwarding, дополнительные темы, зашифрованный бэкап
`.termoshvault`. При попытке открыть — короткое сообщение с предложением
написать разработчику, если функция важна.

## Что проверить

1. Первый запуск с пустым списком серверов — приветствие показывается?
2. Подключение с неверным паролем — понятное сообщение?
3. Импорт `~/.ssh/config` — результат и кнопка «К серверам»?
4. tmux-сессии: включите опцию в сервере, подключитесь, запустите
   что-то долгое (`sleep 600 &`), закройте приложение, откройте через
   5 минут — `fg` должен вернуть ту же сессию.
5. Замок Pro: тап по SFTP → сообщение «В разработке».

## Требования

- Android 14+ (minSdk 34).
- arm64-v8a (все современные телефоны).
